# Speech Dispatcher Server for Emacspeak

A pure Python speech server for Emacspeak that uses Speech Dispatcher (speechd) as the backend text-to-speech service.

## Features

- Pure Python implementation (no TCL required)
- Full support for Emacspeak's voice locking concept via SSML markup
- Speech queue management with proper synchronization
- Support for rate, pitch, and volume adjustments
- Punctuation mode control (none, some, all)
- Capital letter handling (split caps, beep on caps)
- Audio file playback
- Beep/tone generation

## Requirements

- Python 3.7 or later
- Speech Dispatcher (speech-dispatcher package)
- Python bindings for Speech Dispatcher (speech-dispatcher-python or python3-speechd)
- sox (optional, for beep functionality)

### Installing Dependencies

**Fedora/RHEL:**
```bash
sudo dnf install speech-dispatcher speech-dispatcher-python sox
```

**Debian/Ubuntu:**
```bash
sudo apt-get install speech-dispatcher python3-speechd sox
```

**Arch Linux:**
```bash
sudo pacman -S speech-dispatcher python-speechd sox
```

## Usage

### Starting the Server

The server can be run directly:

```bash
./speechd-server.py
```

Or using the wrapper:

```bash
./speechd
```

For debugging with logging:

```bash
./log-speechd
```

### Configuration in Emacspeak

Add to your Emacs configuration:

```elisp
(setq dtk-program "speechd")
```

Or start Emacspeak with:

```bash
emacspeak -o speechd
```

### Using with Emacspeak

Once configured, the server works transparently with Emacspeak:

- `C-e d s` - Stop speech
- `C-e d q` - Quiet (stop and clear queue)
- All standard Emacspeak speech commands work normally

## Voice Locking Support

The server supports Emacspeak's voice locking feature through SSML markup. Voice characteristics are set via SSML `<prosody>` tags:

- **Pitch**: Mapped to speechd pitch parameter
- **Rate**: Mapped to speechd rate parameter  
- **Volume**: Mapped to speechd volume parameter

The server automatically wraps speech in appropriate SSML tags based on the current voice settings from Emacspeak.

## Architecture

The server is organized into several components:

1. **TTSQueue** - Speech queue management (equivalent to tts-lib.tcl)
2. **TTSState** - State management (rate, punctuation, caps mode, etc.)
3. **SSMLBuilder** - SSML markup generation for voice locking
4. **SpeechDispatcherClient** - Interface to Speech Dispatcher
5. **EmacspeakServer** - Main server implementing the Emacspeak protocol

## Protocol Commands

The server implements the standard Emacspeak TTS protocol:

- `q <text>` - Queue speech text
- `c <control>` - Queue control codes (SSML)
- `d` - Dispatch queued speech
- `s` - Stop speaking
- `l <char>` - Speak character/letter
- `t <pitch> <duration>` - Play tone
- `sh <duration>` - Silence
- `a <sound>` - Queue audio file
- `p <sound>` - Play audio file
- `b <pitch> <duration>` - Queue beep
- `r <rate>` - Queue rate change
- `tts_set_speech_rate <rate>` - Set speech rate
- `tts_set_character_scale <factor>` - Set character scale
- `tts_set_punctuations <mode>` - Set punctuation mode
- `tts_split_caps <flag>` - Enable/disable split caps
- `tts_caps <flag>` - Enable/disable caps beep
- `tts_sync_state <punct> <splitcaps> <caps> <rate>` - Sync all state
- `tts_reset` - Reset TTS
- `tts_say <text>` - Direct TTS output

## Troubleshooting

### Server fails to connect

Make sure Speech Dispatcher is running:

```bash
systemctl --user status speech-dispatcher
```

If not running:

```bash
systemctl --user start speech-dispatcher
```

To enable on boot:

```bash
systemctl --user enable speech-dispatcher
```

### Debug mode

Set the `DTK_DEBUG` environment variable:

```bash
DTK_DEBUG=1 ./speechd-server.py
```

Or use the logging wrapper:

```bash
./log-speechd
```

Check the log files in `/tmp/speechd-*.log` and `/tmp/speechd-out-*.log`

### No sound output

1. Check Speech Dispatcher configuration:
   ```bash
   spd-say "test"
   ```

2. Check the output module:
   ```bash
   speech-dispatcher -o  # List available output modules
   ```

3. Check audio system (PulseAudio/ALSA/pipewire)

### Module not found errors

If you get `ModuleNotFoundError: No module named 'speechd'`:

1. Install the Python bindings:
   ```bash
   # Fedora
   sudo dnf install speech-dispatcher-python
   
   # Debian/Ubuntu
   sudo apt-get install python3-speechd
   ```

2. Or install via pip if available:
   ```bash
   pip3 install speechd
   ```
